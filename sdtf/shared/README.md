# `viewer.sdtf.shared`

> Interfaces for the sdtf json content. These interfaces are only used for TypeScript typings and are not meant to be implemented.
> Representation of the SDtf file contents in a TypeScript class hierarchy.

## Install
```
npm install @shapediver/viewer.sdtf.shared
```

Please see the explanation in the [template repository](https://github.com/shapediver/ShapeDiverMonorepoTemplate) for permissions.
