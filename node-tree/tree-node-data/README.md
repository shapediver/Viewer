# `viewer.node-tree.tree-node-data`

> This package manages the node data that can be used in the tree system `viewer.node-tree.tree`.

## Install
```
npm install @shapediver/viewer.node-tree.tree-node-data
```

Please see the explanation in the [template repository](https://github.com/shapediver/ShapeDiverMonorepoTemplate) for permissions.

## Usage

```typescript
import { ITreeNodeData, AbstractTreeNodeData } from '@shapediver/viewer.node-tree.tree-node-data';

```
