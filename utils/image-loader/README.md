# `viewer.utils.image-loader`

> This package can load images to HTMLImageElements.

## Install
```
npm install @shapediver/viewer.utils.image-loader
```

Please see the explanation in the [template repository](https://github.com/shapediver/ShapeDiverMonorepoTemplate) for permissions.

## Usage

```typescript
import imageLoader from '@shapediver/viewer.utils.image-loader';

const: HTMLImageElement = await imageLoader.load('LINK TO AN IMAGE');
```
