# `viewer.utils.http-client`

> This package is a helper for the axios library with some error handling already implemented.

## Install
```
npm install @shapediver/viewer.utils.http-client
```

Please see the explanation in the [template repository](https://github.com/shapediver/ShapeDiverMonorepoTemplate) for permissions.

## Usage

```typescript
import httpClient from '@shapediver/viewer.utils.http-client';

httpClient.get('LINK')
httpClient.post('LINK')

```
